# Lieb Mich — music video

A generative, code-rendered music video with word-synced typography. Every frame is a deterministic function of song time, so the browser preview and the offline export are identical.

The current direction is [`docs/TREATMENT_REVISED.MD`](docs/TREATMENT_REVISED.MD) (with [`docs/SONG_BREAKDOWN.md`](docs/SONG_BREAKDOWN.md)); [`docs/TREATMENT.md`](docs/TREATMENT.md) has the first treatment and how the plates map onto this recording's four-chorus structure. The scene API is in [`docs/ENGINE.md`](docs/ENGINE.md) (the motif functions named in `docs/ENGINE_REVISED.MD` are aspirational: the real ones are in `app/src/scenes/_motifs.ts`).

## Layout

- `audio/liebmich.mp3` — the song. **Not in the repo** (it isn't ours to publish): put your copy of the recording there (4:11; the timing data is aligned to it).
- `lyrics/lyrics.src.js` — the lyric sheet in this recording's structure, with approximate line times (generated by `analysis/sheet.py`).
- `analysis/` — Python (uv) tools that produced the timing data (CPU only).
- `data/lyrics.json` — word-level lyric timings; `data/audio.json` — tempo (135 BPM), beats, downbeats, sections, onsets and envelopes.
- `app/` — the renderer (TypeScript + three.js, bun + Vite). `src/scenes/` holds one module per plate plus `_motifs.ts`; `src/timeline.ts` is the edit.

## Preview

```sh
cd app
bun install
bunx vite
```

Open http://localhost:5173 (`?t=49` starts at a given time). Keys: space play/pause, ←/→ seek, `,`/`.` step a frame, `[`/`]` previous/next scene, `l` loop the scene, `h` hide the UI.

## Render

```sh
cd app
bunx playwright-core install chromium-headless-shell   # Linux, once (macOS uses the installed Chrome)
bun scripts/render.ts sheet --cuts --out ../out/cuts.png          # a frame either side of every cut
bun scripts/render.ts video --samples auto --shutter 0.2 --out ../out/liebmich.mp4
```

`--chrome <path>` (or `$CHROME`) picks a different browser binary. `--codec av1` encodes with SVT-AV1 (10-bit) for ffmpeg builds without libx264, such as Fedora's `ffmpeg-free`.

4K master (3840×2160, 60 fps, adaptive motion blur, 10-bit H.264): `app/scripts/render-4k.sh [out_dir]` — resumable segments, song muxed in. Setup, GPU checks, a 480p preview and all the options: [`docs/RENDERING.md`](docs/RENDERING.md).

## Regenerate the timing data

```sh
cd analysis
uv sync
uv run python -m demucs -n htdemucs -o stems ../audio/liebmich.mp3   # stems (~3 min on CPU)
uv run python measure_offset.py      # stem offset vs the gapless decode -> common.STEM_OFFSET_SAMPLES
uv run python transcribe.py          # Whisper (German) transcript -> work/whisper.json
uv run python sheet.py               # lyric sheet in the recording's structure -> lyrics/lyrics.src.js
uv run python align.py               # word timings (MMS forced alignment) -> data/lyrics.json
uv run python vocal_feats.py && uv run python analyze.py   # -> data/audio.json
```

`align.py` also checks the two lines the supplied sheet had as "Lieb nicht": "Lieb mich" (what the recording sings) fits the audio better in all eight places.
